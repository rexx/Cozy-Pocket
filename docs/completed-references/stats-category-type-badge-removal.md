# 統計頁類別卡牌移除「支出／收入」標籤紀錄

## 摘要

- 統計頁「依照類別分析」的類別卡牌，類別名稱右側原有「支出」或「收入」 pill badge 已移除。
- 由於整組類別卡牌已分組在「支出類別」或「收入類別」群組標題下，個別卡牌上的標籤屬冗餘資訊。
- 卡牌標題列現在僅顯示類別名稱、筆數與佔比，依靠群組標題識別類別屬於支出或收入。

## 實際變更

- `components/MonthlyStatsPage.tsx` 的 `renderCategoryStatsGroup` 中，類別卡牌標題列移除根據 `isIncome` 渲染的型別 pill badge。
- 因 badge 移除而失去意義的內層 `flex items-center gap-2` wrapper 一併移除，類別名稱 `<p>` 直接成為 `min-w-0 flex-1` 容器的子元素，`truncate` 行為維持原樣。
- 群組層級的「支出類別」「收入類別」標題保留，作為 type 屬性的單一資訊來源。
- `type` 與 `isIncome` 變數保留，仍被群組標題顏色與卡牌金額著色使用。
- 子類別展開區塊原本就沒有 type badge，未受影響。

## 驗證

- 執行 `npm run build` 通過（tsc + vite，無 type error）。
- 手動驗證統計頁「依照類別分析」中，支出類別卡牌與收入類別卡牌標題列不再出現 pill badge。
- 驗證類別名稱、筆數百分比、金額、顏色、展開行為、進度條與子類別展開都維持原本表現。
- 驗證多幣別情境下，每個幣別的支出／收入群組分組仍清楚可辨識。

## 假設

- 群組標題「支出類別」「收入類別」足以讓使用者判別類別屬性，不需要在卡牌層級重複標示。
- 若日後改為混合排序（不再依 type 分組），再評估是否需要重新加回 type 視覺指示。
