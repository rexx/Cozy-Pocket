# 首頁週／月日曆切換實作紀錄

本項目已完成並合併回 `main`。最終實作保留月曆檢視，同時新增可收合的週曆檢視，讓首頁可在整月分布與近期交易焦點之間切換。

## 摘要

- 首頁 `Calendar` 支援 `week` 與 `month` 兩種模式，並記住使用者最後一次選擇。
- 月模式保留原本整月格狀月曆；週模式只顯示 `selectedDate` 所在週的 7 天，週起始維持星期一。
- 週／月切換按鈕以浮動圓形箭頭放在日曆與交易列表分界線上，不佔用列表高度。
- 保留既有日期選擇、今天按鈕、搜尋、設定、同步狀態入口，以及下方交易列表左右切日。

## 關鍵變更

- `App.tsx` 持有首頁日曆模式 state，並以 `localStorage` 保存偏好；首次預設仍為月模式。
- `components/Calendar.tsx` 依模式產生月格或單週日期；日曆區左右箭頭與滑動會跟隨模式切月或切週。
- `components/HomePage.tsx` 在日曆下緣渲染浮動圓形展開／收合按鈕，並讓按鈕尺寸與其他首頁箭頭控制保持一致。
- 首頁交易列表仍維持獨立的左右切日前後日行為。

## 介面與型別

- 新增 `CalendarViewMode = 'week' | 'month'` 型別。
- `HomePage` 接收目前日曆模式與切換 callback，再傳入 `Calendar` 控制日期格線。
- 不變更 `Transaction` 資料模型與同步資料格式。

## 測試計劃

- 執行 `npm run build`。
- 手動驗證首次進入首頁為月模式，切換後重新整理會記住最後模式。
- 手動驗證週模式顯示正確 7 天，月模式顯示整月格線。
- 手動驗證日曆區左右滑動與左右箭頭在週模式切週、月模式切月。
- 手動驗證下方交易列表左右滑動仍切前後日。
- 手動驗證有交易的日期標記、今天樣式、週末顏色、非本月日期顏色仍可辨識。

## 假設

- 週起始日維持目前月曆邏輯的星期一。
- 週／月切換只影響首頁日曆顯示與日曆區導覽語意，不改統計頁或交易資料模型。
