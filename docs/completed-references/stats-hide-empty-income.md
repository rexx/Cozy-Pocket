# 統計頁隱藏空收入區塊完成紀錄

本項目讓統計頁在目前期間與篩選條件下沒有收入資料時，依幣別整段隱藏收入相關區塊，避免空狀態佔用畫面。

## 完成內容

- 在 `MonthlyStatsPage` 渲染每個幣別時依 `statsByCurrency[currency].income > 0` 計算 `hasIncome`。
- 沒有收入時不渲染收入摘要卡、收入明細展開區與「收入類別」分組，畫面只剩支出區塊與類別彙整。
- 有收入時保留原本的收入金額卡片、展開明細與收入類別排序、子類別與展開行為。
- 「依類別彙整」標頭右側的類別數量改為只計算實際顯示的群組，沒有收入時不再把收入類別納入計數。
- 篩選條件（tag、支付方式、排除子類別）改變後 `hasIncome` 會跟著重新判斷；篩選後變成沒有收入時，收入區塊整段消失。
- 多幣別時每個幣別獨立判斷，某幣別只有收入沒有支出時仍正常顯示收入區塊。

## 介面與資料

- 沒有新增 `statsService` 型別或 service API；直接使用既有的 `statsByCurrency`、`filteredTransactions` 與 `categoryStatsByCurrency`。
- 沒有新增 persisted settings 或交易欄位；`hasIncome` 為 render-time 推導。
- 支出區塊與既有空資料 fallback（`沒有符合條件的支出項目`、`沒有支出類別資料`）維持不變。

## 驗證

- 已執行 `npm run build`（tsc strict + Vite production build 皆通過）。
- 預期手動驗證：只有支出的月份／年份不再出現收入明細與收入類別整段。
- 預期手動驗證：有收入的月份／年份維持原本顯示與展開行為。
- 預期手動驗證：套用 tag、支付方式、排除子類別後讓某幣別只剩支出時，收入區塊同步隱藏。
- 預期手動驗證：多幣別情境下每個幣別獨立顯示或隱藏收入區塊。
