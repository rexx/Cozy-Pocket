# 商家詳情頁實作計劃

本項目實作時會使用新的 git worktree 進行開發，不直接修改目前 repo 根目錄；建議 worktree 路徑為 `worktrees/merchant-detail-page`，完成後再由該分支提交與合併。

## 摘要

- 從商家管理進入單一商家詳情頁，讓使用者不只整理名稱，也能快速理解該商家的消費型態。
- 詳情頁聚焦該商家的消費趨勢、常用類別、付款方式分布與最近交易。
- 第一版以既有 `transactions` state 與 `TransactionItem` 呈現為主，不新增商家資料模型。

## 關鍵變更

- 在商家管理選取商家後提供進入商家詳情頁的操作。
- 新增 `MerchantDetailPage` 或等效頁面元件，顯示商家名稱、總交易數、最近交易時間與分幣別總額。
- 彙整該商家的常用類別、常用付款方式與近期交易列表。
- 趨勢第一版可先用月份彙整清單或簡易區塊，不急著導入圖表套件。
- 交易列表沿用既有 `TransactionItem`，點擊後仍可進入既有編輯流程。

## 介面與型別

- 不變更 `Transaction` 資料模型；商家仍由交易的 `merchant` 欄位推導。
- 若需要彙整 helper，優先新增在既有 service 層，避免把統計邏輯塞進頁面 JSX。
- 若同時進行 IndexedDB 資料來源改造，商家詳情頁可改為依商家名稱查詢交易。

## 測試計劃

- 執行 `npm run build`。
- 手動驗證從商家管理進入商家詳情頁與返回流程。
- 驗證中文、英文、含空白商家名稱都能正確查詢與顯示。
- 驗證多幣別交易不混算，類別與付款方式分布筆數正確。
- 驗證最近交易可點入編輯，返回後仍保留原本商家詳情脈絡。

## 假設

- 第一版不新增 chart library，除非現有 UI 無法清楚呈現趨勢。
- 第一版不建立商家主檔；alias、商家標籤或商家備註另列後續功能評估。
