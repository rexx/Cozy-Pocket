# 首頁週曆顯示實作計劃

本項目實作時會使用新的 git worktree 進行開發，不直接修改目前 repo 根目錄；建議 worktree 路徑為 `worktrees/home-week-calendar`，完成後再由該分支提交與合併。

## 摘要

- 將首頁 `Calendar` 從整月格狀月曆改為單週顯示，讓首頁第一屏保留更多交易列表空間。
- 保留既有日期選擇、左右滑動、月份切換、今天按鈕、搜尋、設定與同步狀態入口。
- 週顯示以目前選取日期所在週為核心，週起始維持星期一。

## 關鍵變更

- 調整 `components/Calendar.tsx` 的日期產生邏輯，從 `eachDayOfInterval(monthStart..monthEnd)` 改為產生 `selectedDate` 所在週的 7 天。
- 將原本月切換的左右箭頭語意改為週切換，點擊後選取上一週或下一週的對應日期。
- 保留 header 的日期 input；當使用者直接選日期時，同步重新計算該日期所在週。
- 檢查 `components/HomePage.tsx` 的上方容器高度與陰影，避免週曆縮小後留下多餘空白。

## 介面與型別

- 優先不變更 `CalendarProps`；若需讓父層知道週切換，可新增可選 callback，但預設仍透過既有 `onDateSelect` 驅動。
- 不變更 `Transaction` 資料模型與同步資料格式。

## 測試計劃

- 執行 `npm run build`。
- 手動驗證今天、月底、跨月週、跨年週都能顯示正確的 7 天。
- 手動驗證左右滑動與左右箭頭切換週後，交易列表會跟著選取日期更新。
- 手動驗證有交易的日期標記、週末顏色、非本月日期顏色仍可辨識。

## 假設

- 週起始日維持目前月曆邏輯的星期一。
- 本項目只改首頁月曆密度，不新增月/週模式切換。
