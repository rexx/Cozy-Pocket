# 統計頁隱藏空收入區塊實作計劃

本項目實作時會使用新的 git worktree 進行開發，不直接修改目前 repo 根目錄；建議 worktree 路徑為 `worktrees/stats-hide-empty-income`，完成後再由該分支提交與合併。

## 摘要

- 統計頁在目前期間與篩選條件下沒有收入資料時，隱藏整個收入相關區塊。
- 目標是讓只有支出的月份或年份更精簡，避免空收入明細與空收入類別佔用畫面。
- 支出區塊與既有空資料狀態維持不變。

## 關鍵變更

- 在 `MonthlyStatsPage` 依幣別計算 `hasIncome`，例如收入總額大於 0 或收入交易筆數大於 0。
- 沒有收入時，不渲染收入明細展開入口與收入類別統計群組。
- 有收入時維持目前收入金額、收入明細、收入類別排序與展開行為。
- 篩選條件改變後即時重新判斷；例如原本有收入但套用 tag 後沒有收入，就隱藏收入區塊。
- 若某幣別只有收入沒有支出，仍正常顯示收入區塊，不因支出缺資料而隱藏。

## 介面與型別

- 不需要新增 service 型別；可使用既有 `statsByCurrency`、`filteredTransactions` 與 `categoryStatsByCurrency`。
- 不新增 persisted settings 或交易欄位。

## 測試計劃

- 執行 `npm run build`。
- 手動驗證只有支出資料時，收入明細與收入類別整段不出現。
- 手動驗證有收入資料時，收入區塊維持原本顯示與展開行為。
- 驗證月份／年份、tag、支付方式與排除子類別篩選後，收入區塊顯示或隱藏會同步更新。
- 驗證多幣別情境下，每個幣別獨立判斷是否顯示收入區塊。

## 假設

- 本項目只隱藏統計頁中的收入區塊，不改首頁摘要卡或交易資料模型。
